# 外链手册

首页 `/` 提供 575 个预置平台的搜索、自定义标签、笔记与外链日志。
页面右上角可切换“跟随系统 / 日间模式 / 夜间模式”，默认跟随系统。外观偏好单独保存在当前浏览器，刷新和切换页面后保留；系统模式会随设备外观自动更新。
点击外链库上方“＋ 添加外链”，填写名称、网址和选填说明即可添加个人外链。网址可省略 `https://`，重复网址会提示；新增外链显示在列表前面，支持搜索、标签与笔记，最多添加 1000 个。
自定义外链与其他个人记录一起本地保存、JSON 备份和云端同步，不会写入公开的预置目录。
数据位于 `src/data/external-links.json`，将 Web.Cafe 网页存档里的 693 条可见推荐整理为 349 个网站的简明说明，合并重复内容并去掉评论者姓名。没有内容资料的网站不补写结论。
明确的费用信息显示为“免费”“收费”标签，支持点击筛选，可与个人标签和搜索组合使用；两种方式明确并存的可同时显示两个费用标签。费用不明确或资料存在无法解释的分歧时不标注，不显示“待确认”标签。价格和提交条件仅反映历史资料，未经逐站重新核实。
卡片上的费用标签可以编辑：点击标签旁的 × 移除，或展开“编辑费用标签”添加／移除“免费”“收费”。移除需确认并可立即撤销；全部移除后不显示任何费用标签。个人选择优先于预置资料，筛选同步更新，刷新、导入导出和跨设备同步都会保留修改。
个人标签由用户自行添加，与费用标签分开显示。卡片中输入名称即可添加标签，
也可选择已创建的标签；点击标签查看同类外链，点击 × 移除卡片标签或删除全局标签。
移除前会显示确认对话框，默认聚焦取消。全局标签会移入回收站，保留原来的外链关联；支持立即撤销、刷新后恢复，以及云端跨设备同步回收站。回收站中的每个标签都支持“彻底删除”，确认后永久移除标签及原关联，不能撤销；外链和笔记保留。卡片上的标签移除也需要确认，并提供撤销。
旧版浏览器记录和备份会自动升级到 v6，移除旧版预设标签，保留用户自建标签、关联和笔记。
卡片直接显示一段平台说明，不再列出原评论、评论人名和评论条数。
外链以标签、费用和搜索组织，不再提供熟悉度状态、评分、统计或复习功能。旧备份的兼容字段继续保留，编辑笔记不会丢失其他个人记录。

个人外链、标签和笔记保存在浏览器 localStorage，页面支持 JSON 导入与导出，
整理后的说明和费用标签列表保存在 `public/data/external-links.csv`。新设备需要手动导入备份。
可选的个人云端同步使用 Cloudflare Workers + D1，无需自行维护服务器；配置后通过个人同步口令在不同设备同步自定义外链、标签、笔记和外链日志。未配置时仍使用原有本地存储。实现、冲突处理与部署步骤见 [个人外链同步](docs/personal-link-sync.md)。
纯逻辑检查：`node --experimental-strip-types --test scripts/link-library.test.mjs`。
部署沿用推送 main 后的 GitHub Pages workflow，正式地址为 https://builtbyluna.cc/ ，原 `/links/` 地址继续可用，规范地址统一指向首页。

## 主题手册

`/handbooks/` 展示手册目录，`/handbooks/<id>/` 提供独立的手册页。初始发布「多语言文章推广」，引用现有外链库中的 14 个平台；原型中的示例手册和私人笔记不发布。

外链列表和手册页共用 `LinkCard`，保留费用、个人标签、平台说明和笔记的原有交互。卡片新增只读的「手册说明」区块：按外链 ID 汇总所有关联手册的说明，每份说明链接回对应手册并定位到该平台。章节切换和平台深链接均可直接打开、刷新；标签和费用筛选在手册中同样生效。

公开内容维护于 `src/data/handbooks.ts`：`handbooks` 保存标题、简介与章节，`handbookEntries` 用手册 ID、章节 ID、已有外链 ID 及说明建立关联。增加手册时补充这两份数据，静态页面会随构建生成。手册说明采用正文展示，不提供输入框，也不引入实践记录、验证状态或示例日志。

个人标签、笔记、费用修改仍使用同一份 v6 本地记录、备份和云端同步；本次不修改个人数据结构或 Worker，无需数据库迁移。


站点发布外链手册与外链日志，博客文章页、分类页和博客导航已下线。原文章 Markdown 保留在 `src/content/blog/`，不会生成公开页面。

## 外链日志

点击导航“外链日志”（`/#journal`），按天填写工作内容、成功发布的外链数和经验与下一步，点击“保存日志”。每个日期保留一篇，支持补记、编辑、按月筛选、搜索及删除后撤销。日志为空时不添加示例工作记录。

日志与标签、笔记共用本地保存、JSON 备份及个人云端同步。数据格式升级为 v6，兼容 v1/v2/v3/v4/v5；旧备份没有日志，导入会清空现有日志，导入前请导出备份。云端上线前先部署新版 Worker，再发布前端；无需数据库迁移。新版 Worker 会保留旧页面写入时未识别的日志、自定义外链及其笔记和标签关联，旧页面读取 v6 数据后需要刷新。

### 自动操作记录（v7）

外链日志按本地日期展示标签添加、移除和恢复（包括费用标签）、笔记新增／修改／删除、自定义外链新增／修改／删除。每条操作保留当时的外链名称、网址及变更内容；删除外链后历史仍保留。内置目录仍只读，自定义外链可编辑和删除。手写日报继续独立保存，删除日报不会删除当天自动记录。

笔记编辑后点击“保存笔记”提交，每次实际保存生成一条操作，保留保存前后内容；未修改时按钮禁用。未保存草稿在当前页面筛选和分页时保留，离开页面会提醒；同步更新时保留草稿并提示重新载入，避免覆盖。历史不会按条数自动裁剪，存储或同步容量不足时保留本机数据并显示错误。导入 v1～v6 备份会把自动操作记录迁移为空，替换前应导出当前记录。

发布 v7 必须先执行 `npm run sync:deploy` 更新 Worker，再推送前端；GitHub Pages workflow 不部署 Worker。无需数据库迁移。新版 Worker 会保留 v1～v6 旧页面无法识别的自动记录；旧页面应刷新后继续使用。
