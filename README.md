# 外链手册

首页 `/` 提供 575 个预置平台的搜索、自定义标签、笔记与外链日志。
点击外链库上方“＋ 添加外链”，填写名称、网址和选填说明即可添加个人外链。网址可省略 `https://`，重复网址会提示；新增外链显示在列表前面，支持搜索、标签与笔记，最多添加 1000 个。
自定义外链与其他个人记录一起本地保存、JSON 备份和云端同步，不会写入公开的预置目录。
数据位于 `src/data/external-links.json`，将 Web.Cafe 网页存档里的 693 条可见推荐整理为 349 个网站的简明说明，合并重复内容并去掉评论者姓名。没有内容资料的网站不补写结论。
明确的费用信息显示为“免费”“收费”标签，支持点击筛选，可与个人标签和搜索组合使用；两种方式明确并存的可同时显示两个费用标签。费用不明确或资料存在无法解释的分歧时不标注，不显示“待确认”标签。价格和提交条件仅反映历史资料，未经逐站重新核实。
个人标签由用户自行添加，与费用标签分开显示。卡片中输入名称即可添加标签，
也可选择已创建的标签；点击标签查看同类外链，点击 × 移除卡片标签或删除全局标签。
移除前会显示确认对话框，默认聚焦取消。全局标签会移入回收站，保留原来的外链关联；支持立即撤销、刷新后恢复，以及云端跨设备同步回收站。回收站中的每个标签都支持“彻底删除”，确认后永久移除标签及原关联，不能撤销；外链和笔记保留。卡片上的标签移除也需要确认，并提供撤销。
旧版浏览器记录和备份会自动升级到 v5，移除旧版预设标签，保留用户自建标签、关联和笔记。
卡片直接显示一段平台说明，不再列出原评论、评论人名和评论条数。
外链以标签、费用和搜索组织，不再提供熟悉度状态、评分、统计或复习功能。旧备份的兼容字段继续保留，编辑笔记不会丢失其他个人记录。

个人外链、标签和笔记保存在浏览器 localStorage，页面支持 JSON 导入与导出，
整理后的说明和费用标签列表保存在 `public/data/external-links.csv`。新设备需要手动导入备份。
可选的个人云端同步使用 Cloudflare Workers + D1，无需自行维护服务器；配置后通过个人同步口令在不同设备同步自定义外链、标签、笔记和外链日志。未配置时仍使用原有本地存储。实现、冲突处理与部署步骤见 [个人外链同步](docs/personal-link-sync.md)。
纯逻辑检查：`node --experimental-strip-types --test scripts/link-library.test.mjs`。
部署沿用推送 main 后的 GitHub Pages workflow，正式地址为 https://builtbyluna.cc/ ，原 `/links/` 地址继续可用，规范地址统一指向首页。


站点发布外链手册与外链日志，博客文章页、分类页和博客导航已下线。原文章 Markdown 保留在 `src/content/blog/`，不会生成公开页面。

## 外链日志

点击导航“外链日志”（`/#journal`），按天填写工作内容、成功发布的外链数和经验与下一步，点击“保存日志”。每个日期保留一篇，支持补记、编辑、按月筛选、搜索及删除后撤销。日志为空时不添加示例工作记录。

日志与标签、笔记共用本地保存、JSON 备份及个人云端同步。数据格式升级为 v5，兼容 v1/v2/v3/v4；旧备份没有日志，导入会清空现有日志，导入前请导出备份。云端上线前先部署新版 Worker，再发布前端；无需数据库迁移。新版 Worker 会保留旧页面写入时未识别的日志、自定义外链及其笔记和标签关联，旧页面读取 v5 数据后需要刷新。
